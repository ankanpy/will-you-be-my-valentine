# Will You Marry Me? 💍

An interactive, romantic marriage proposal web application built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**.

Designed to ask the most important question in the sweetest, most unforgettable way! ✨

## ✨ Features & Interactive Highlights

- 🌸 **Romantic Glassmorphism Design**: Soft blush and rose pastel mesh gradient (`from-rose-100 via-pink-50 to-rose-200`) paired with a frosted glass card container (`backdrop-blur-xl bg-white/80`) and delicate ambient glowing orbs.
- 💍 **Floating Rings & Ambient Hearts**: Continuous upward-drifting diamond rings (`💍`), hearts (`💖`), and sparkles (`✨`) floating in the background.
- 🪄 **Interactive Click Sparkles**: Clicking or tapping anywhere on the screen bursts floating ring and heart particles at the exact click location.
- 💓 **Heartbeat Dynamic "Yes" Button**: A pulsing heartbeat animation on the "Yes" button that grows progressively larger each time "No" is clicked.
- 🙈 **Playful Shy "No" Button**: Interactive wiggle animation on click, cycling through an escalating sequence of humorous, heartfelt pleading phrases.
- 🎉 **Grand Celebration Climax**:
  - Full-screen colorful heart & sparkle confetti shower powered by `canvas-confetti`.
  - Affectionate kissing bear celebration GIF.
  - Special *"💍 She said YES! Forever & Always ✨"* badge with a *"Play again ↺"* replay option.
- 🔤 **Elegant Typography**: Styled with Google Fonts (*Playfair Display*, *Dancing Script*, and *Quicksand*).
- 📱 **Fully Responsive**: Flawlessly optimized for mobile phones, tablets, and desktops.

## 🚀 Getting Started Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ankanpy/will-you-be-my-valentine.git
   cd will-you-be-my-valentine
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Open in your browser:**
   Visit [http://localhost:5173/](http://localhost:5173/) to review the app locally with instant hot-reload!

## 📦 How to Deploy to GitHub Pages

Deploying your customized version takes just one command:

```bash
npm run deploy
```

This command runs `vite build` and automatically pushes the compiled assets to your repository's `gh-pages` branch using the `gh-pages` package.

### First-Time GitHub Setup:
1. In your GitHub repository, navigate to **Settings** → **Pages** (in the left sidebar).
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select **Branch: `gh-pages`** and folder **`/ (root)`**, then click **Save**.
4. Within 1–2 minutes, your proposal site will be live!
